# Contributing to FDE Interview Prep

Thank you for helping build a transparent, community-driven resource for Forward Deployed Engineer (FDE) interview preparation! 

We welcome contributions in the form of new decomposition questions, company-specific format notes, rubric refinements, and resource links.

---

## What You Can Contribute

1. **Sample Decomposition Questions (`questions/decomposition-round.md`):**
   - High-leverage, ambiguous business scenarios sourced from real interview experiences.
   - Please include key evaluation focus areas (e.g., data constraints, compliance, adoption bottlenecks).

2. **Company-Specific Notes:**
   - Insights on interview round formats, evaluation criteria, and expectations at specific companies (e.g., Palantir, OpenAI, Anthropic, C3.ai, Scale AI, BCG X).
   - > [!IMPORTANT]
   - > **NDA & Privacy Notice:** All contributions MUST be strictly anonymized and non-NDA violating. Do NOT share proprietary code, exact confidential question wording from active NDA agreements, or private internal documentation.

3. **Rubric Refinements (`rubrics/decomposition-round.md`):**
   - Additions to client simulation rubrics, trade-off signal nuances, or practical tips for candidates.

4. **Resource Links (`resources.md`):**
   - Quality articles, video walkthroughs, tools, or open-source guides relevant to FDE roles.

---

## How to Submit a Pull Request

1. **Fork the repository** and create a feature branch for your changes:
   ```bash
   git checkout -b feature/add-new-question
   ```
2. **Make your edits** following existing Markdown formatting styles.
3. **Verify relative links** between documents (e.g., linking back to `README.md` or `rubrics/`).
4. **Commit your changes** with a clear commit message:
   ```bash
   git commit -m "docs: add healthcare IoT decomposition sample question"
   ```
5. **Open a Pull Request** against the `main` branch.
